## `3. Порядок участия` 

```
Для возможности участия в хакатоне команды должны соответствовать следующим
требованиям:
```

- `Все участники должны быть старше 18 лет.` 

- `Каждый участник может состоять только в одной команде.` 

- `Большая часть участников команды должна присутствовать очно.` 

- `Количество участников в команде не должно превышать 6-ти человек.` 

```
Мероприятие организационно включает следующие основные этапы:
```

- `Сбор и регистрация участников.` 

- `Подготовка к соревнованиям.` 

- `Проведение соревнований, подведение итогов, награждение.` 

```
Подробное расписание и актуальные организационные изменения своевременно
публикуются на странице мероприятия и в чате.
```

- `Представление организаторов, описание правил и дополнительных условий этапов подготовки и соревнования.`

### `3.2 Подготовка к соревнованиям` 

```
Все доступное время на площадке отводятся для подготовки к соревнованиям.
```

```

доступные временные слоты. Команда, занявшая временной слот в обозначенное
время, имеет приоритет на использование полигона. Другие команды в это

самостоятельно.
```

```
Для предоставления актуальной информации и разрешения неоднозначных и
спорных ситуаций на площадке проводятся собрания капитанов команд.
```

```
На площадке всегда будет находиться организатор, к которому, в случае
необходимости, следует обращаться для решения организационных и базовых

### `3.3 Проведение соревнований, подведение итогов, награждение` 

```
Соревнования проходят в последний день мероприятия.
```

```
За полчаса до начала соревнований доступ к полигону и роботам всех
участников блокируется для подготовки полигона к соревнованиям. Команды
заблаговременно фиксируют все результаты работы, выключают роботов и
передают их наставникам хакатона.
```

```
Команды получают доступ к роботам только с предоставляемого организационным
комитетом компьютера и только для запуска своего решения.
```

```
Очередность выступления команд определяется случайным образом.
```

```
Во время соревнований выступление каждой команды протоколируется
организаторами и судьями хакатона. Ответственность за взаимодействие с
организаторами и судьями хакатона от лица команды берет на себя капитан,
который должен своевременно сообщать об этапах подготовки и ключевых
решениях во время выступления.
```

```
Подведение итогов и выбор призовых мест производится после окончания
соревнований.
```

```
Награждение победителей происходит после подведения итогов на общей
площадке РобоФиниста.
```

```



```
Конфигурация полигона станет известна участникам в первый день мероприятия

```
Статические препятствия расставляются на полигоне в заранее неизвестном но

- `Высота от 0.15 [м].` 

- `Непрозрачные и не зеркальные поверхности.`

### `5.2 Порядок проведения соревнований` 

```
Во время соревнований команды выступают попарно в формате турнира на
выбывание. Каждый матч состоит из двух симметричных этапов по 10 минут.
Перед выступлением роботы двух соответствующих команд  подключаются к
отдельной организаторской Wi-Fi-сети и ставятся на отведённую для старта
площадку с ограничительными линиями на полу.
```

```
Подготовка робота к выступлению проводится только с предоставляемых
организаторами ПК и только через ssh. Включение и подключение к роботу
происходит до начала этапа.
```

```
После начала этапа обеим командам дается 4 минуты на подготовку. Роботы при
этом не должны пересекать ограничительную линию своей стартовой площадки
(freeze time). По окончании времени на подготовку роботы могут приступать к
выполнению задач независимо от готовности команды соперника. Если робот
пересек ограничительную линию раньше времени, то он принудительно
возвращается на стартовую позицию.
```

```
Этап может быть полностью перезапущен один раз по запросу капитанов обеих
команд или по решению организаторов. Капитан команды может останавливать
этап, фиксируя тем самым максимальный балл для команды противника.
```

```
Во время соревнований запрещено фиксировать в ПО робота информацию, которая
прямо или косвенно связана с заранее неизвестными особенностями испытаний.
```

```
Редактирование исходного кода решения допускается только в момент
подготовки робота до момента пересечения им ограничительной линии стартовой
площадки и только после согласования с организатором мероприятия.
```

```
Формат проведения хакатона подразумевает равные аппаратные возможности всех
участников. По этой причине установка и использование дополнительной
сенсорики, сетевого оборудования или средств для увеличения
производительности предоставляемого бортового ПК робота не допускаются.
```

```
Ввиду характера заданий не допускается кастомизация конструкции или
изменение внешнего вида робота.
```

### `5.3 Задачи и оценка` 

```
В рамках каждого этапа команды поочерёдно выступают в ролях исследователя
(explorer) и стража (guardian). Этап заканчивается, если
робот-исследователь достиг стартовой площадки стража, был пойман стражем
или закончилось время на этап. Если робот-исследователь не был пойман, то
этап засчитывается в пользу исследователя.
```

```
Подробная количественная информация о балльной системе будет предоставлена
участникам в первый день проведения хакатона.
```

```
5/6
```

```
Победителем матча является команда, которая набрала наибольшее количество
баллов за оба этапа. Призовые места формируются на основе результатов
финала турнира.
```

```
Достижением исследователем стартовой площадки стража считается момент
касания контуром робота контура площадки (событие a на рисунке).
```

```
Поимкой робота-исследователя считается момент, когда расстояние между СК
роботов менее 0.45 м. (~ 0.1 м. между корпусами), ось Х стража не более чем
на 45 град. отклонена от прямой между СК роботов и между роботами
отсутствуют препятствия (событие b на рисунке).
```



```
Для однозначности трактовки событий судьями мероприятия участникам
рекомендуется сделать информативную индикацию в терминал.
```

```
За столкновения со статическими препятствиями штрафы не начисляются.
Полигон условно считается неподвижным, но в случае смещения критических для
проведения этапа его элементов организаторы могут перезапустить этап.
```

```
Организационный комитет хакатона оставляет за собой приоритет при
разрешении спорных ситуаций и право о назначении штрафов и дисквалификации.
```
